# Project Statement

## Student Attendance Management System

The purpose of this project is to create a simple Python application for maintaining student attendance records.

The system stores student details, records attendance date-wise, calculates attendance percentages, allows records to be searched and updated, and produces a basic attendance report.

The application uses JSON for local storage and is designed as a menu-driven console program. It is intended to demonstrate practical use of Python fundamentals such as functions, lists, dictionaries, file handling, validation, and testing.
