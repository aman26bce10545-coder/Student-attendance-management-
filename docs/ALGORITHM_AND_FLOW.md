# Algorithm and Flow

## Main flow

Start -> Load JSON -> Main Menu -> Select operation -> Validate input -> Perform operation -> Save changes -> Main Menu -> Exit

## Attendance percentage

1. Count recorded attendance entries.
2. Count entries with status `P`.
3. Calculate `present / total * 100`.
4. If there are no entries, return 0%.

## Low attendance

Calculate each student's percentage and list students whose percentage is below 75%.

## Search

Check students one by one until the requested roll number is found.
